MAANWIN PANNEL — Android Studio project

This is a fresh demo app project using the supplied MAANWIN PANNEL logo and registration URL:
https://maanwin21.com/register?inviteCode=JKKCDZN&from=web

The prediction button generates RANDOM DEMO labels only. It does not access or predict real game results.

BUILD APK:
1. Install Android Studio on a computer.
2. Open the folder MaanwinPannel (the folder containing settings.gradle).
3. Let Android Studio sync/download the Android Gradle plugin and SDK platform 35.
4. Choose Build > Build Bundle(s) / APK(s) > Build APK(s).
5. Android Studio will show the output APK path (usually app/build/outputs/apk/debug/app-debug.apk).

No compiled APK is included because this environment does not have Gradle/Android SDK installed to build and verify one.
